# 🌿 Daily Todolist · 薄荷待办

> 在一天的天色变化中感受时间的流逝。

一个薄荷绿主色的每日待办网页。页面颜色会跟着北京时间变化，从清晨的晨曦，到午后的湖青、黄昏的落日、傍晚的蓝调，再到夜晚的粉调。每次打开页面，颜色都在提醒你：今天又过去了一点。

🔗 **在线使用：** https://moonpie-cr.github.io/daily-todolist/

---

## ✨ 功能

### 🕰 北京时间电子钟
- 固定按北京时间（UTC+8）显示时、分、秒，电脑在其他时区也不会错
- 显示日期和星期，冒号会闪烁
- 底部有一条 0:00–24:00 的进度条，白点标出现在的位置，并显示"今天已经过去 xx%"和"距离今天结束还有 x 小时 x 分"

### 🎨 随时间变化的颜色

| 时间 | 时段 | 色调 |
|---|---|---|
| 05:00–07:00 | 🌅 清晨 · 晨曦 | 蜜桃橘 → 浅薄荷 |
| 07:00–11:00 | 🌿 上午 · 薄荷 | 薄荷绿 |
| 11:00–14:00 | ☀️ 正午 · 晴光 | 青柠 → 薄荷 |
| 14:00–17:00 | 🍃 午后 · 湖青 | 薄荷 → 湖蓝 |
| 17:00–18:30 | 🌇 黄昏 · 落日 | 金黄 → 橘 → 玫瑰 |
| 18:30–20:00 | 🌆 傍晚 · 蓝调 | 天蓝 → 靛蓝 → 淡紫 |
| 20:00–23:00 | 🌙 夜晚 · 粉调 | 樱粉 → 紫 |
| 23:00–05:00 | 🌌 深夜 · 星河 | 深靛紫 |

- 打开页面时自动换成当前时段的颜色；页面一直开着，到下一个时段也会自动换色
- 点进度条上的任意一段，可以预览那个时段的配色，点「↺ 回到此刻配色」恢复

### 📝 每日待办
- 添加待办时可以设置时间、优先级（重要 / 一般 / 随意）和分类（学习 / 写稿 / 采访 / 生活 / 运动 / 其他）
- 点圆圈完成，双击文字编辑，点 ☆ 标为重要
- 列表自动排序：未完成在前，重要在前，有时间的按时间先后
- 可以筛选"全部 / 未完成 / 已完成"
- 以前没做完的事会提醒你，一键移到今天

### 📅 周日历
- 一排显示 7 天，每天下面有小进度条
- 点日期切换到那天，左右箭头翻周，可以提前安排或回看

### 🌱 右侧小工具
- **进度圆环**：今日完成百分比、已完成 / 待完成 / 重要未做的数量
- **分类完成度**：每个分类完成了多少
- **连续打卡**：当天待办全部完成即打卡一天
- **心情和小记**：选一个表情，写几句当天的感想
- 每天一句小短句
- 当天待办全部完成时，会飘一阵彩带 🎉

### 🌗 其他
- 浅色 / 深色主题一键切换
- 手机和电脑都能用，窄屏自动改成上下排列
- 快捷键：按 `/` 直接跳到输入框

## 🚀 使用方法

**在线使用**：打开上面的网址即可。手机浏览器里选"添加到主屏幕"，用起来像一个小 App。

**本地使用**：下载 `index.html`，用浏览器（Chrome / Edge / Safari 等）打开，不需要联网，也不需要安装。

---

## 🔒 关于数据

- 所有待办、心情和小记**只保存在你自己的浏览器里**（localStorage），不会上传到任何服务器
- 每个人打开同一个网址，各写各的，互相看不到
- 换浏览器、换设备或清除浏览器数据后，记录不会保留
- 部分预览环境不允许网页保存数据，这时页面能正常显示，但刷新后待办不会保留
